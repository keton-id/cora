# @keton-id/cora-PLATFORM-ARCH

Prebuilt `cr` binary for **PLATFORM / ARCH**. This package is normally consumed transitively by [`@keton-id/cora`](https://www.npmjs.com/package/@keton-id/cora) as an `optionalDependency` — the meta package's launcher resolves the matching subpackage for the host at runtime.

Install the meta package instead unless you have a specific reason to pin a single platform:

```sh
npm i -g @keton-id/cora
```

Full docs: <https://github.com/keton-id/cora>
